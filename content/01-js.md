@@@ js-01 | event-loop, async
Как работает Event Loop? В каком порядке выполнятся синхронный код, промисы и `setTimeout`?
???
JS однопоточный. Есть **стек вызовов**, очередь **микрозадач** (промисы, `queueMicrotask`, `MutationObserver`) и очередь **макрозадач** (`setTimeout`, события, I/O).

Цикл: выполнить синхронный код до опустошения стека → **все** микрозадачи → отрисовка (если нужна) → **одна** макрозадача → снова все микрозадачи…

```js
console.log(1);
setTimeout(() => console.log(2));
Promise.resolve().then(() => console.log(3));
console.log(4);
// 1 4 3 2
```

@@@ js-02 | замыкания, функции
Что такое замыкание? Приведи практический пример.
???
Функция + лексическое окружение, в котором она создана. Функция «помнит» переменные внешней области, даже когда внешняя функция уже завершилась.

```js
function counter() {
  let n = 0;
  return () => ++n;
}
const next = counter();
next(); // 1
next(); // 2
```

Применение: приватное состояние, фабрики функций, debounce/throttle, мемоизация, хуки React (и их ловушка — устаревшее замыкание).

@@@ js-03 | this, функции
Как определяется `this`?
???
Зависит от **способа вызова**, а не от места объявления:

- `obj.method()` → `obj`
- обычный вызов `fn()` → `undefined` в strict mode (иначе `globalThis`)
- `new Fn()` → новый объект
- `fn.call(ctx)`, `apply`, `bind` → `ctx`
- стрелочная функция своего `this` не имеет — берёт из внешней области

Ловушка: `const m = obj.method; m()` — контекст потерян.

@@@ js-04 | переменные, tdz
Чем отличаются `var`, `let` и `const`? Что такое TDZ?
???
- `var` — область видимости функции, всплывает со значением `undefined`, можно переобъявить.
- `let`/`const` — блочная область. Тоже всплывают, но до строки объявления находятся во **временной мёртвой зоне** (TDZ): обращение → `ReferenceError`.
- `const` запрещает переприсваивание, но не делает объект неизменяемым.

```js
for (var i = 0; i < 3; i++) setTimeout(() => console.log(i)); // 3 3 3
for (let j = 0; j < 3; j++) setTimeout(() => console.log(j)); // 0 1 2
```

@@@ js-05 | hoisting, переменные
Что такое hoisting (всплытие)?
???
При создании контекста объявления «поднимаются»:

- **Function Declaration** — целиком, можно вызвать до объявления;
- `var` — со значением `undefined`;
- `let`, `const`, `class` — без инициализации (TDZ).

Function Expression ведёт себя как переменная:

```js
hi(); // работает
function hi() {}

bye(); // TypeError: bye is not a function
var bye = () => {};
```

@@@ js-06 | сравнение, типы
Разница между `==` и `===`? Чему равно `NaN === NaN`?
???
`===` сравнивает без приведения типов, `==` приводит: `'1' == 1`, `0 == ''`, `null == undefined` — всё `true`. Используй `===`. Исключение — `x == null` как короткая проверка на `null`/`undefined`.

`NaN === NaN` → `false`. Проверка: `Number.isNaN(x)` или `Object.is(x, NaN)`. А ещё `Object.is(0, -0)` → `false`.

@@@ js-07 | прототипы, ооп
Как работает прототипное наследование?
???
У каждого объекта есть скрытая ссылка `[[Prototype]]` (`Object.getPrototypeOf(obj)`). При чтении свойства JS идёт по **цепочке прототипов**, пока не найдёт его или не дойдёт до `null`.

`class` — синтаксический сахар над прототипами: методы лежат в `Class.prototype`.

```js
const animal = { eat() { return "ест"; } };
const cat = Object.create(animal);
cat.eat(); // "ест" — найдено в прототипе
```

@@@ js-08 | промисы, async
Чем отличаются `Promise.all`, `allSettled`, `race` и `any`?
???
- `all` — ждёт все; падает при **первом** reject.
- `allSettled` — ждёт все и никогда не падает: `[{ status, value | reason }]`.
- `race` — результат первого завершившегося (успех или ошибка).
- `any` — первый **успешный**; если упали все — `AggregateError`.

`all` — для независимых запросов, которые нужны все. `allSettled` — когда устраивает частичный успех.

@@@ js-09 | async, промисы
Как обрабатывать ошибки в async/await? Что будет, если забыть `await`?
???
`try/catch` вокруг `await` или `.catch()` у промиса. Без `await` функция сразу вернёт промис, ошибка уйдёт в unhandled rejection, и `try/catch` её не поймает.

Последовательно или параллельно:

```js
// медленно: запросы по очереди
const a = await getA();
const b = await getB();

// быстро: параллельно
const [a2, b2] = await Promise.all([getA(), getB()]);
```

@@@ js-10 | debounce, задачи
Чем debounce отличается от throttle? Напиши debounce.
???
**debounce** — вызвать один раз после паузы (поиск при вводе). **throttle** — не чаще раза в N мс (scroll, resize).

```ts
function debounce<A extends unknown[]>(fn: (...args: A) => void, ms: number) {
  let t: ReturnType<typeof setTimeout>;
  return (...args: A) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
```

@@@ js-11 | this, функции
`call`, `apply`, `bind` — в чём разница?
???
Все три задают `this`:

- `call(ctx, a, b)` — вызывает сразу, аргументы списком;
- `apply(ctx, [a, b])` — вызывает сразу, аргументы массивом;
- `bind(ctx, a)` — **возвращает новую функцию** с привязанным контекстом (и частично применёнными аргументами).

Повторный `bind` контекст не меняет. На стрелочные функции не действуют.

@@@ js-12 | объекты, копирование
Поверхностное и глубокое копирование. Как скопировать объект глубоко?
???
Spread `{...obj}` и `Object.assign` копируют только верхний уровень — вложенные объекты остаются общими.

Глубоко: `structuredClone(obj)` — поддерживает `Date`, `Map`, `Set`, циклические ссылки; не копирует функции и DOM-узлы.

`JSON.parse(JSON.stringify(obj))` теряет `undefined` и функции, а `Date` превращает в строку.

@@@ js-13 | коллекции
`Map` против `Object`, `Set`, `WeakMap` — когда что?
???
- **Map** — ключи любого типа, порядок вставки, есть `size`, быстрые частые добавления и удаления.
- **Object** — записи с заранее известными строковыми ключами.
- **Set** — уникальные значения: `[...new Set(arr)]`.
- **WeakMap / WeakSet** — ключи только объекты, держатся слабо и не мешают сборке мусора. Подходят для кэша и метаданных к объектам, не итерируются.

@@@ js-14 | dom, события
Что такое всплытие и делегирование событий?
???
Событие проходит фазы: **погружение** (от `window` к цели) → цель → **всплытие** (обратно вверх).

Делегирование — один обработчик на родителе вместо сотни на детях:

```js
list.addEventListener("click", (e) => {
  const item = e.target.closest("li");
  if (item) select(item.dataset.id);
});
```

`e.target` — где кликнули, `e.currentTarget` — где висит обработчик. `stopPropagation()` останавливает всплытие.

@@@ js-15 | массивы, иммутабельность
Какие методы массива мутируют исходный массив? Какие есть иммутабельные аналоги?
???
Мутируют: `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse`, `fill`.

ES2023 добавил копирующие версии: `toSorted()`, `toReversed()`, `toSpliced()`, `with(i, v)`. В React и Redux состояние мутировать нельзя — используй их или spread.

Ловушка: `[10, 9, 1].sort()` → `[1, 10, 9]`, потому что сортирует как строки. Нужно `sort((a, b) => a - b)`.

@@@ js-16 | типы
Какие типы данных есть в JS? Что вернёт `typeof null`?
???
7 примитивов: `string`, `number`, `bigint`, `boolean`, `undefined`, `symbol`, `null` — и `object` (включая массивы и функции). Примитивы передаются по значению, объекты — по ссылке.

`typeof null === "object"` — историческая ошибка языка. `typeof function () {}` → `"function"`. Массив проверяй через `Array.isArray`.

@@@ js-17 | модули
Чем ES-модули отличаются от CommonJS?
???
**ESM** (`import`/`export`) — статические: импорты известны до выполнения, поэтому работают tree-shaking и top-level `await`. Экспорт — **живая привязка**, загрузка асинхронная.

**CommonJS** (`require`/`module.exports`) — динамический и синхронный, экспортирует копию значения.

В браузере и современных бандлерах стандарт — ESM.

@@@ js-18 | операторы
Что делают `?.` и `??`? Чем `??` отличается от `||`?
???
`a?.b?.()` — безопасный доступ: вернёт `undefined`, если `a` — `null` или `undefined`.

`??` подставляет значение только для `null`/`undefined`, а `||` — для **любого** falsy (`0`, `''`, `false`):

```js
const count = 0;
count || 10; // 10 — неожиданно
count ?? 10; // 0
```

@@@ js-19 | память
Как работает сборщик мусора и откуда берутся утечки памяти?
???
Алгоритм **mark-and-sweep**: от корней (глобальный объект, стек) помечается всё достижимое, остальное удаляется.

Утечка — объект, который остался достижимым по ошибке:

- забытые таймеры и подписки (`addEventListener` без удаления);
- замыкания на большие данные;
- растущие глобальные кэши;
- ссылки на удалённые DOM-узлы.

В React — эффекты без cleanup.

@@@ js-20 | браузер, производительность
Что происходит, когда браузер рисует страницу (critical rendering path)?
???
HTML → **DOM**, CSS → **CSSOM** → Render Tree → **Layout** (геометрия) → **Paint** (пиксели) → **Composite** (слои).

- изменение `width` или `top` → layout (дорого);
- `color` → paint;
- `transform` и `opacity` → только composite, на GPU. Поэтому анимируют их.

Чтение `offsetHeight` сразу после записи стилей вызывает принудительный layout (layout thrashing).

@@@ js-21 | сеть, async
Как отменить fetch-запрос?
???
Через `AbortController`:

```ts
const controller = new AbortController();

fetch(url, { signal: controller.signal }).catch((e) => {
  if (e.name === "AbortError") return;
  throw e;
});

controller.abort();
```

В React отменяют в cleanup эффекта, чтобы не было гонок при смене параметров. Для таймаута: `AbortSignal.timeout(5000)`.

@@@ js-22 | сеть, безопасность
Что такое CORS и почему возникает ошибка?
???
Браузер блокирует ответы на запросы к другому **origin** (протокол + домен + порт), если сервер не разрешил это заголовком `Access-Control-Allow-Origin`.

Для «непростых» запросов (PUT, JSON, свои заголовки) сначала уходит preflight `OPTIONS`.

Чинится на **сервере** или через прокси, не на клиенте. Это защита браузера: curl и запросы сервер → сервер CORS не касается.

@@@ js-23 | браузер, хранилища
`cookie`, `localStorage`, `sessionStorage`, IndexedDB — в чём разница?
???
- **cookie** — ~4 КБ, уходит на сервер с каждым запросом. Может быть `HttpOnly` — тогда недоступна JS (так хранят сессию).
- **localStorage** — ~5 МБ, синхронный, бессрочный, только строки.
- **sessionStorage** — то же, но живёт до закрытия вкладки.
- **IndexedDB** — асинхронная БД на сотни МБ: объекты, индексы, транзакции.

Это приложение хранит карточки в IndexedDB.

@@@ js-24 | иммутабельность, функции
Что такое чистая функция и иммутабельность? Почему это важно в React?
???
**Чистая функция** — результат зависит только от аргументов, побочных эффектов нет. **Иммутабельность** — данные не меняем, а создаём новые.

React и Redux сравнивают состояние **по ссылке** (`Object.is`). Мутация не меняет ссылку → ререндера не будет:

```js
setItems([...items, x]);       // ✓ новый массив
items.push(x); setItems(items); // ✗ та же ссылка
```

@@@ js-25 | безопасность
Что такое XSS и как от него защититься?
???
Внедрение чужого скрипта через пользовательские данные.

React экранирует текст в JSX, но опасны `dangerouslySetInnerHTML`, `href="javascript:…"`, `innerHTML` и `eval`.

Защита: не вставлять сырой HTML (или чистить через DOMPurify), Content-Security-Policy, токены в `HttpOnly` cookie, а не в localStorage.

@@@ js-26 | итераторы, генераторы
Что такое итераторы и генераторы?
???
**Итератор** — объект с методом `next()`, который возвращает `{ value, done }`. Объект **итерируемый**, если у него есть метод `[Symbol.iterator]`: тогда работают `for...of`, spread и деструктуризация.

**Генератор** (`function*`) — функция, которая умеет приостанавливаться на `yield` и продолжать с того же места. Она возвращает итератор.

```js
function* ids() {
  let id = 1;
  while (true) yield id++; // бесконечная, но ленивая последовательность
}
const gen = ids();
gen.next().value; // 1
gen.next().value; // 2

const range = {
  from: 1,
  to: 3,
  *[Symbol.iterator]() {
    for (let i = this.from; i <= this.to; i++) yield i;
  },
};
[...range]; // [1, 2, 3]
```

@@@ js-27 | proxy, метапрограммирование
Что такое `Proxy` и где он применяется?
???
Обёртка над объектом, которая перехватывает операции: чтение, запись, удаление, `in` и другие. `Reflect` выполняет операцию по умолчанию.

```js
const user = { name: "Ann", age: 30 };
const watched = new Proxy(user, {
  set(target, key, value) {
    console.log(`${String(key)}: ${target[key]} → ${value}`);
    return Reflect.set(target, key, value);
  },
});
watched.age = 31; // "age: 30 → 31"
```

На Proxy построены реактивность Vue 3, черновики Immer (их использует Redux Toolkit), MobX. Также — валидация, логирование, значения по умолчанию.

@@@ js-28 | циклы, ловушка
Чем `for...in` отличается от `for...of`?
???
- `for...in` перебирает **ключи** (строки) объекта, включая унаследованные перечисляемые свойства.
- `for...of` перебирает **значения** итерируемого объекта: массива, строки, `Map`, `Set`.

```js
const arr = ["a", "b"];
arr.extra = "!";

for (const i in arr) console.log(i); // "0", "1", "extra"
for (const v of arr) console.log(v); // "a", "b"
```

Для массивов — `for...of` (или методы массива). Для объектов — `Object.keys/values/entries` + `for...of`.

@@@ js-29 | массивы, группировка
Как сгруппировать массив объектов по полю?
???
Современный способ (ES2024) — `Object.groupBy`:

```js
const people = [
  { name: "Ann", dept: "dev" },
  { name: "Bob", dept: "qa" },
  { name: "Kim", dept: "dev" },
];

Object.groupBy(people, (p) => p.dept);
// { dev: [Ann, Kim], qa: [Bob] } — объект без прототипа

Map.groupBy(people, (p) => p.dept); // то же, но в Map
```

Классика для собеса — через `reduce`:

```js
const byDept = people.reduce((acc, p) => {
  (acc[p.dept] ??= []).push(p.name);
  return acc;
}, {});
// { dev: ["Ann", "Kim"], qa: ["Bob"] }
```
